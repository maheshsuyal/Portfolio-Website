# 💼 Personal Portfolio Website

A modern and responsive personal portfolio website built with **React.js** to showcase my projects, technical skills, education, and experience. The website provides a clean and interactive interface, allowing visitors to explore my work and easily get in touch.

## 🚀 Live Demo

🔗 **Portfolio:** https://maheshfolio.netlify.app/

## ✨ Features

* Responsive design for all devices
* Modern and clean user interface
* About Me section
* Skills showcase
* Featured Projects
* Education & Experience
* Contact section
* Fast performance and smooth navigation

## 🛠️ Tech Stack

* React.js
* JavaScript (ES6+)
* HTML5
* CSS3
* React Icons
* Netlify (Deployment)
